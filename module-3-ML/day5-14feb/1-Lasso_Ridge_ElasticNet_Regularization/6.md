# 🎯 Bias–Variance vs Hyperparameters

Hyperparameters control **model complexity**.
Model complexity directly controls **bias and variance**.

👉 This is the core connection.

---

# 🧠 First: Quick Recap

* **Bias** → Error due to overly simple assumptions
* **Variance** → Error due to sensitivity to training data

[
Total\ Error = Bias^2 + Variance + Irreducible\ Error
]

# 🎛️ How Hyperparameters Control Bias & Variance

Different hyperparameters directly shift the model on this curve.

---

## 🌳 1️⃣ Decision Tree – `max_depth`

| max_depth     | Bias     | Variance |
| ------------- | -------- | -------- |
| Small (2-3)   | High     | Low      |
| Medium (5-10) | Balanced | Balanced |
| Very Large    | Low      | High     |

👉 Increasing depth → more complex → variance increases.

---

## 📈 2️⃣ Linear Regression – Regularization (λ)

### Ridge / Lasso

| λ (Regularization Strength) | Bias | Variance |
| --------------------------- | ---- | -------- |
| High λ                      | High | Low      |
| Low λ                       | Low  | High     |

👉 Strong regularization simplifies model → increases bias, reduces variance.

---

## 🧠 3️⃣ KNN – `k`

| k            | Bias | Variance |
| ------------ | ---- | -------- |
| Small (k=1)  | Low  | High     |
| Large (k=50) | High | Low      |

👉 Small k = very flexible → high variance.

---

## 🌲 4️⃣ Random Forest – `n_estimators`

More trees:

* Bias ≈ same
* Variance ↓

Because averaging reduces variance.

---

# 🔥 What GridSearchCV Really Does

When tuning hyperparameters:

You are searching for the **bias–variance sweet spot**.

GridSearchCV chooses parameters that:

* Minimize validation error
* Balance bias and variance

---

# 📊 Training vs Validation Behavior

| Scenario                      | Training Error | Validation Error | Problem |
| ----------------------------- | -------------- | ---------------- | ------- |
| Both High                     | High Bias      | Underfitting     |         |
| Training Low, Validation High | High Variance  | Overfitting      |         |
| Both Low                      | Balanced       | Ideal            |         |

---

# 🎯 Interview 60-Second Answer

“Hyperparameters control model complexity, which directly affects bias and variance. Increasing complexity reduces bias but increases variance, while simplifying the model increases bias but reduces variance. Hyperparameter tuning methods like GridSearchCV aim to find the optimal balance that minimizes validation error.”
