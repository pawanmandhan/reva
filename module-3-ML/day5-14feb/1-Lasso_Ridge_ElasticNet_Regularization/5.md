# 🎯 GridSearchCV vs RandomizedSearchCV

Both are used for **hyperparameter tuning** in `sklearn`.

The difference is **how they explore the parameter space**.

---

# 🔵 1️⃣ GridSearchCV

### 📌 Idea

Tries **all possible combinations** of hyperparameters you specify.

If:

```python
max_depth = [3, 5, 10]
min_samples_split = [2, 5]
```

Total models trained:

[
3 × 2 = 6
]

### ✅ Advantages

* Exhaustive search
* Guaranteed to check every combination
* Good when search space is small

### ❌ Disadvantages

* Computationally expensive
* Very slow for large parameter ranges

---

# 🎲 2️⃣ RandomizedSearchCV

### 📌 Idea

Tries **random combinations** from parameter distributions.

You specify:

* Parameter ranges
* Number of iterations (`n_iter`)

Example:

```python
n_iter = 20
```

It randomly samples 20 combinations — even if total possible combinations are 1000+.

### ✅ Advantages

* Much faster
* Works well for large search spaces
* Often finds near-optimal solution

### ❌ Disadvantages

* Not exhaustive
* May miss best combination (but rare if n_iter is good)

# ⚖️ Side-by-Side Comparison

| Feature              | GridSearchCV          | RandomizedSearchCV    |
| -------------------- | --------------------- | --------------------- |
| Search Type          | Exhaustive            | Random Sampling       |
| Speed                | Slow                  | Faster                |
| Best For             | Small parameter space | Large parameter space |
| Control              | Exact combinations    | Number of iterations  |
| Risk of Missing Best | No                    | Possible              |

---

# 🧠 Practical Rule

* Few parameters, small range → **GridSearchCV**
* Many parameters, wide range → **RandomizedSearchCV**
* Very large space → RandomizedSearchCV usually better

Fun fact:
In high-dimensional spaces, **Random Search often outperforms Grid Search** (research-backed).

---

# 🐍 Example

### GridSearchCV

```python
from sklearn.model_selection import GridSearchCV
grid = GridSearchCV(model, param_grid, cv=5)
grid.fit(X, y)
```

### RandomizedSearchCV

```python
from sklearn.model_selection import RandomizedSearchCV
random = RandomizedSearchCV(model, param_distributions, 
                            n_iter=20, cv=5)
random.fit(X, y)
```

# 🎯 Interview 30-Second Answer

“GridSearchCV exhaustively tries all hyperparameter combinations, while RandomizedSearchCV samples a fixed number of random combinations from parameter distributions. Grid search is suitable for small search spaces, whereas randomized search is more efficient for large or high-dimensional spaces.”
